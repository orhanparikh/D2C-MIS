# Archetypes — how the three common D2C shapes behave

The skill asks the founder's category once and uses it to set defaults, tune note text, and pick the
bands the Checks tab uses. Structure never changes by archetype; only defaults and guidance do.

| | BPC (beauty & personal care) | F&B (packaged food, nutrition) | Apparel & accessories |
|---|---|---|---|
| Typical GM | 55–70% | 30–45% (50% for premium) | 50–62% |
| GST default | 18% | 12% (5% staples, 18% some snacks; ask) | 5% below ₹1,000 MRP, 12% above → ~10% blended |
| Returns + RTO, % gross | 5–12% (mostly RTO on COD) | 1–5% | 35–55% incl. exchanges; refunds 10–15%, RTO 8–13%, exchanges 20–30% |
| Returns lines | Single "Returns & RTO" | Single | Split: RTO · Returns refunded · Exchanges · (gift-card refunds if used) |
| Logistics % NSR | 8–12% | 9–12% (bulk to Qcom is cheaper) | 12–20% of NSR, 8–12% of GMV (reverse logistics) |
| Marketing % NSR | 35–50%, RoAS 2–3× | 10–30%, RoAS 3–9× | 35–50% of website NSR, RoAS 1.7–2.7× |

## Edge cases the notes should anticipate
- **Marketplace on B2B terms** (partner raises PO, brand invoices at net): treat commission as trade margin
  (revenue deduction), returns near zero, COGS on sell-in. GM% will be noisy month to month.
- **Quick commerce**: partner buys stock; brand funds consumer promos; receivables 30–45 days. Ask where promos go.
- **COD-heavy website**: RTO 15–30% of COD orders. Track RTO separately from customer returns.
- **Own manufacturing**: conversion cost is real (labour, power); put in COGS, not people.
- **Trading (buy finished goods)**: COGS = landed purchase cost incl. inbound freight and import duty.
- **Founder salary**: if unpaid, still note it. Investors add it back in.
- **Ad spend on GST invoices**: enter marketing excluding GST (input credit). Note says so.
- **Shopify "Total sales" vs "Gross sales"**: gross sales is before discounts and returns; use that as GMV.
- **Amazon settlement vs Amazon business report**: business report gives GMV; settlement gives fees. Both needed.
- **Exchanges**: in apparel, count the returned unit as a return and the re-shipped unit as new gross, or net
  them. Pick one and record it on Start Here.
